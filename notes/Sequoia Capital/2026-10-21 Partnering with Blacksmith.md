# Partnering with Blacksmith

**Source**: [Sequoia Capital](https://www.sequoiacap.com/article/partnering-with-blacksmith)
**Author**: Sequoia Capital (featuring JP, Aayush and Maru) | **Date**: Oct 21, 2026

---

## Summary

Sequoia profiles Blacksmith, a company founded by JP, Aayush, and Maru that is building infrastructure to help developers validate and ship trustworthy code at the speed AI agents can write it. The core idea is that code verification must keep pace with agent-driven code generation.

## Key Takeaways

- **Treat verification as core infrastructure:** As agents generate code faster, invest in automated validation layers so review and testing do not become the bottleneck.
- **Match validation speed to generation speed:** Evaluate whether your current testing and CI pipeline can keep up with agent output volume before scaling agent use.
- **Make trust measurable:** Define concrete checks for correctness and safety on agent-written code so shipping decisions rely on evidence rather than intuition.
- **Shift developer effort toward judgment:** Let tooling handle routine validation so engineers can focus on reviewing high-risk changes and architectural decisions.
