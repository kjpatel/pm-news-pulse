## Summary

This episode explores how to build practical AI agents and workflows without extensive technical expertise, featuring a code review bot built in 30 minutes with Vercel Eve and a non-technical founder who rebuilt her business around Claude skills.

## Key Takeaways

- **Separate low-risk from high-risk automatically** by creating a clear scoring system (like the 6-dimensional risk model) that determines which PRs can skip human review and which require it, making AI-assisted code review safer and faster.
- **Use intent engineering over prompt perfection** by giving Claude enough context about your goals and problems, then letting it propose solutions rather than spending time on perfectly crafted prompts.
- **Build internal agents in single sessions** using tools like Vercel Eve that handle infrastructure (OAuth, tokens, permissions) through browser automation, reducing setup from hours to minutes.
- **Create a 'think like you' guide** that captures your decision-making philosophy, values, and communication style in voice notes and markdown, allowing AI to learn how you work and bring better-informed suggestions.
- **Move context out of siloed tools** by handling workflows (like email) inside Claude instead of Gmail, so every interaction compounds into smarter future decisions rather than getting buried.
