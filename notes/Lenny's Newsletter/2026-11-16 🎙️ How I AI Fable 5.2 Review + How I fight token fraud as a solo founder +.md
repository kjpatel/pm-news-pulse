## Summary

Scott Farrar, a math educator and parent, argues that persistent Markdown files in Claude Code work better than long AI chats for managing household knowledge, because chats suffer from memory drift. He shows how a shared Obsidian-based system can organize a family's tasks, warranties, and decisions while AI still supports rather than replaces human thinking.

## Key Takeaways

- **Store context in files you can inspect and correct.** Keep your AI's memory in Markdown files rather than inside a chat window, so you can review, fix, and reuse that context across sessions.
- **Let the AI tell you what it needs.** Ask the assistant what information would help it do the job, then gather that input. Scott's example: Claude suggested photographing every appliance, which became a searchable inventory of model numbers, serials, and warranties.
- **Feed raw input and let the system organize it.** Dump unstructured notes into the system and let the AI maintain the files, and add guardrails such as a custom linter to stop agents from bloating documents.
- **Use AI to sharpen your decisions, not outsource them.** Give the AI detailed context before a decision like comparing insurance quotes, so it can spot coverage gaps and help you prepare specific follow-up questions.
- **Choose shared tools based on how your household actually works.** When GitHub added more complexity than his wife wanted, Scott used GitHub for shared scripts and Dropbox for everyday files, and surfaced key tasks on a wall display the whole family sees.
