## Summary

Scott Farrar argues that a folder of Markdown files, viewed in Obsidian and managed through Claude Code, can serve as a persistent household knowledge base that avoids the drift and forgetting of ordinary AI chats. He also argues that AI should keep kids doing the thinking rather than thinking for them.

## Key Takeaways

- **Move recurring life admin out of chat and into a persistent file system.** Store appliances, warranties, insurance documents, and to-dos as Markdown files that Claude Code can read every session, so context doesn't reset each time.
- **Let AI tell you what to gather before you act.** Ask Claude what to photograph or document first, such as appliance labels and policy details, so that tasks like insurance shopping or repairs start with complete information.
- **Use AI to sharpen comparison shopping rather than to decide for you.** Have the model pull your policy details and compare options, then verify the recommendations yourself before buying.
- **Share one household brain across partners.** Keep a single shared to-do file and knowledge base so both people work from the same current state, and surface priority tasks and recent wins on a visible wall display to drive follow-through.
- **Design AI tutoring so kids teach the AI.** Use a flipped setup where the child explains concepts to the model, which keeps the cognitive work with the learner and builds student agency.
