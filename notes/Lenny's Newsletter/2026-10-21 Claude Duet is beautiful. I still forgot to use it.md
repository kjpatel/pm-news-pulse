# Claude Duet is beautiful. I still forgot to use it

**Source**: [Lenny's Newsletter](https://www.lennysnewsletter.com/p/claude-duet-is-beautiful-i-still)
**Author**: Lenny Rachitsky (featuring Claire Vo) | **Date**: Oct 21, 2026

---

## Summary

Claire Vo tests Anthropic's new personal agent, Claude Duet, and finds it the most polished agent launch she has seen, with thoughtful onboarding and useful primitives. She argues that polish is not enough: its passive design, slow responses, and missing desktop and multiplayer support keep it from becoming a daily-use agent.

## Key Takeaways

- **Test personal agents on your real workload before judging them.** Vo ran Duet on her inbox, Slack, sales pipeline, Google Docs deck, launch video, and ticket hunting, which surfaced gaps that a demo would miss.
- **Design for proactivity, not just responsiveness.** A personal agent that never nudges you gets forgotten, so set up scheduled check-ins or surfaced task suggestions to keep it in your routine.
- **Account for latency when delegating synchronous work.** Slow model responses break the flow of back-and-forth, so reserve the agent for asynchronous tasks where waiting is acceptable.
- **Use task lists, artifacts, and channels as reusable agent building blocks.** Organizing work into these primitives makes outputs easier to review, reuse, and route across tools.
- **Check for desktop and multiplayer support before adopting a tool into your working stack.** Missing these features limits when and with whom you can actually use the agent, which can keep it out of daily work.
