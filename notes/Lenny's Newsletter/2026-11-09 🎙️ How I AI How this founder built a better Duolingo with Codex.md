# 🎙️ How I AI: How this founder built a better Duolingo with Codex

**Source**: [Lenny's Newsletter](https://www.lennysnewsletter.com/p/how-i-ai-how-this-founder-built-a)
**Author**: Lenny Rachitsky (featuring William Imoh) | **Date**: Nov 09, 2026

---

## Summary

William Imoh, founder of Mural, explains how he used Codex and GPT-Live to build native iOS and Android language-tutor apps without prior Swift or Kotlin experience. He argues that agents make the founder's product judgment, PM discipline, and clear agent roles more important than any specific programming language.

## Key Takeaways

- **Choose the stack based on the product, not your existing skills.** Let the agent build in the platform-native language (Swift for iOS, Kotlin for Android) when the product needs a native feel.
- **Articulate taste as concrete design direction.** When the first output misses the mood, redirect it with specific instructions such as color palette, gradients, and visual weight rather than vague feedback.
- **Write requests as epics and user stories tied to user problems.** This PM-style structure gives agents clearer goals and produces more consistent results.
- **Budget for real-time voice costs before building around them.** A 30-minute GPT-Live session runs about $3 to $5, so model the per-session cost against the value you deliver and the price of a human alternative.
- **Restart stalled agents with smaller steps and a reviewer.** Start a fresh session, break the task into steps, ask the agent to inspect its own work, and use a second agent to review output from another tool.
