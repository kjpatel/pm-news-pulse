# What Kind of Factory Will You Build?

**Source**: [Tomasz Tunguz](https://tomtunguz.com/what-kind-of-factory-will-you-build/)
**Author**: Tomasz Tunguz | **Date**: Nov 22, 2026

---

## Summary

The article argues that the best engineering teams now build software factories, systems where shared context, skills and specs, an agent, an execution trace, and a curator loop continuously improve the work. The same four-part loop applies to company knowledge, marketing, ads, and sales, so the real question is what kind of factory to build.

## Key Takeaways

- **Log every agent run as an execution trace:** Record what shipped, what broke, and what it cost, so each run produces data you can use to improve the next one.
- **Assign a curator on a fixed cadence:** Have a named owner read the traces regularly and rewrite the skills and specs, since a factory that isn't curated stays flat.
- **Treat shared context as core infrastructure:** Keep the specs, docs, and history that agents read before starting work current, because this context defines what agents can do.
- **Budget for operations, not just model access:** Factories require people to own context, write specs, read traces, and run curation, so plan for that ongoing work rather than a one-time model purchase.
- **Apply the loop to non-engineering teams:** Map marketing campaign performance, ad ROAS data, and sales call transcripts into the same context, agent, trace, and curator structure.
