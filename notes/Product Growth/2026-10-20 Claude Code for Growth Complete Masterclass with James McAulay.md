# Claude Code for Growth: Complete Masterclass with James McAulay

**Source**: [Product Growth](https://www.news.aakashg.com/p/claude-code-for-growth)
**Author**: Aakash Gupta (featuring James McAulay) | **Date**: Oct 20, 2026

---

## Summary

Growth can now be run by a single person with Claude Code: a self-improving Growth OS wires together analytics, Git, and SEO tools, and lets growth teams ship experiments without waiting on engineers. The article also argues that agent autonomy is overhyped, so the human still has to steer.

## Key Takeaways

- **Adopt tools with good APIs or CLIs first.** Connect analytics (such as PostHog via MCP) and read-only Git access as early as possible, since these give the agent the data and context it needs.
- **Write every experiment down before it ships.** Give each experiment a file with its metric, baseline, and confounders up front, and use a weekly retro to force learnings at the end so results build on each other.
- **Gate growth work with a PRD and a multi-agent critique.** Draft a PRD that names the metric the change should move, run it through a multi-agent refine step for critique, and only then ask Claude Code to build.
- **Pair SEO audits with real data and tooling.** Use Firecrawl to convert sites to Markdown, DataForSEO for cheap keyword research, and the Lighthouse CLI for page speed, then have the agent turn findings into a concrete action plan.
- **Plan for a human in the loop.** Treat agents as useful for routine work and self-improvement, but expect to supervise them, since many autonomous claims are overstated and produce low-value token spend.
