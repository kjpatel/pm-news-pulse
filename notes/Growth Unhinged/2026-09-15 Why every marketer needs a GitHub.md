# Why every marketer needs a GitHub

**Source**: [Growth Unhinged](https://www.growthunhinged.com/p/why-every-marketer-needs-a-github)
**Author**: Kyle Poyar (featuring Louise de Sadeleer) | **Date**: Sep 15, 2026

---

## Summary

Louise de Sadeleer argues that marketers will need a public GitHub profile to be hireable, since it showcases AI-built skills, prompts, dashboards, experiments, and projects that demonstrate product thinking. She also gives a practical setup guide for branding the profile and publishing work so non-technical people can use it.

## Key Takeaways

- **Publish what you build.** Share skills, agents, prompts, dashboards, content pipelines, experiments, and personal apps in public repos, since these are the proof of AI-for-GTM skills that employers increasingly look for.
- **Create a profile README with a short, concrete bio.** Include where you work, where you post, and what you're into, and link to your YouTube, X, or other channels so the GitHub profile works like a portfolio landing page.
- **Use the GitHub CLI with Claude to speed up setup.** Install the GitHub CLI so you can ask Claude to create a public repo named after your username with a profile README, instead of clicking through the website.
- **Give every repo a consistent format.** Include a cover image, a description of what the project does, the problem it solves, and installation instructions written for non-technical users, with explainer videos, GIFs, or workflow diagrams where possible.
- **Treat repos as a distribution channel.** Pin your most-starred projects, share them on social platforms, and encourage forks and stars, since helpful shared code is what draws followers and builds visibility.
