# How to build your AI GTM system

**Source**: [Growth Unhinged](https://www.growthunhinged.com/p/how-to-build-your-ai-gtm-system)
**Author**: Kyle Poyar (featuring Matteo Tittarelli) | **Date**: Sep 15, 2026

---

## Summary

Matteo Tittarelli argues that AI GTM efforts stop compounding when teams rely on one-off prompts and ad hoc outputs. He proposes a four-layer Claude Code system (context, skills, orchestration, integrations) in which every artifact feeds the next and stale positioning and brand drift get refreshed automatically.

## Key Takeaways

- **Build a context layer first:** Create always-loaded markdown files (CLAUDE.md plus icp/, competitors/, positioning/, messaging/, and brand/ folders) so every skill and agent reads from the same source of truth before producing anything.
- **Give each GTM function its own skill with defined inputs and outputs:** Specify what each skill reads, the output schema, an example of good output, and the destination folder, so results from one lane sharpen the next.
- **Automate refresh cycles with orchestration:** Set up an agent that checks when skills such as win-loss analysis last ran and triggers them on new call transcripts, routing the output into ICP refreshes without manual commands.
- **Connect the tools your GTM already uses:** Feed skills from sources like Exa, Granola, Gong, Apollo, and HubSpot, and route outputs to channels like Buffer, Google Ads, and Smartlead, so context flows in and content flows out.
- **Guard against brand drift across agents:** Keep a shared voice and tone guideline that every agent and founder reads from, so automated posts still sound like the founder rather than generic AI copy.
