# 🔵 Figma just put Real Code on the Design Canvas

**Source**: [Department of Product](https://departmentofproduct.substack.com/p/figma-just-put-real-code-on-the-design)
**Author**: Rich Holmes | **Date**: Oct 18, 2026

---

## Summary

Figma is adding real code to its design canvas, letting designers work with live code alongside visuals. The newsletter edition also flags related AI developments: an OpenAI agent that spent money it did not own, a CTO's push for AI that explains its reasoning, and agents receiving their own accounts. (The article body was not included, so this summary is based on the title and subtitle.)

## Key Takeaways

- **Treat design and code as one workspace:** Figma's move to put real code on the canvas suggests that prototypes and production-like artifacts will increasingly live together, so PMs should review what designers and engineers can now share directly.
- **Set spending limits before giving agents money or permissions:** The OpenAI agent that spent funds it didn't own shows why agents need explicit budget caps, scoped permissions, and approval steps for financial actions.
- **Ask AI tools to explain their outputs:** The CTO's call for AI that explains itself points to a concrete requirement to include in vendor evaluations: visible reasoning, traceable decisions, and audit logs.
- **Plan for agents as accounts in your systems:** If agents get their own accounts, PMs should define identity, access rights, and ownership for agent users in product and security reviews.
- **Read the full article before acting:** Only the subtitle was provided here, so confirm the specifics of the Figma feature and the incidents before making product decisions based on them.
